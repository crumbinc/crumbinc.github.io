Backups

Back up and restore your diary

Crumb keeps your diary on your phone and has no account, so a backup file is how you keep it safe and how you move it. This page shows how to make one, keep it safe and restore it.

Already testing an earlier version?

Read Moving from an earlier test version before you install anything. Make the backup first.

1. Make a backup

  1. In Crumb, open Me, Backup and data.
  2. Under Backup file, tap Create backup.
  3. Android asks where to save it. Pick a folder on the phone, a drive or any place the file picker offers. The file name starts with crumb-backup-, then the date and time, and ends in .zip.
  4. Crumb says Backup saved.

Automatic backups

Crumb can back up by itself. Under Scheduled backup, choose Daily or Weekly, then tap Choose a folder. Files to keep sets how many copies stay, and the oldest is removed first. Back up now runs one straight away. If Crumb loses access to the folder, it tells you and asks you to choose it again. Scheduled backups are off until you turn them on.

What a backup holds

Your foods, recipes with their plans, cooking history and shopping list, diary entries, quick adds, search history, favourites, weight, water, goals and settings, and your photos.

What stays on the phone only

  • Your Android permissions, such as camera and notifications. You allow them again after a restore, and every one is optional.
  • Reminder permissions, the folder you picked for scheduled backups, and whether you finished setup, so setup runs again on a new install.
  • Your Google Cloud Vision key, if you turned on Read labels online. A backup is not locked, so the key is never put in it. After a restore, add the key again and accept the Read labels online consent again.
  • Downloaded offline food data. Crumb fetches it again if you want it.
  • Your acceptance of the health and legal notice. You see it once on each install.

2. Keep it safe

A backup on the phone is lost with the phone. Copy it somewhere else: a cloud drive, a computer by USB cable, or an email to yourself.

The file is not locked. It holds your weight, body details and photos, so keep it private. A synced folder sends a copy to that cloud service.

Never send your backup to Crumb support. It is your private diary, and we never need it.

3. Restore

On a new install

  1. Open Crumb and accept the health and legal notice.
  2. On the first setup step, tap Restore from a backup and choose your file.
  3. Crumb shows what is inside. Check it and tap Restore.
  4. The Backup restored page lists the permissions Crumb can use. Allow what you want. All are optional. Tap Finish.

Later, from the app

Open Me, Backup and data and tap Restore from file. Backups from older versions of Crumb work too. Under Restore as, choose how:

  • Merge adds what is missing and keeps what is here. Goals and settings come from the file. Pick this when you have been using Crumb since the backup and want to keep what you added.
  • Replace deletes what is in Crumb now and uses the file instead. Crumb asks you to confirm, and keeps a copy of your current data until you close Crumb, so you can undo it.

If Crumb says the file is not a Crumb backup, or was made by a newer version, nothing was changed. For a newer version, update Crumb and try again.

4. Moving from an earlier test version

If you tested Crumb before it reached Google Play, you probably installed it from a file. Move your diary like this.

  1. Back up in the old copy. Open Me, Backup and data and tap Create backup.
  2. Copy the file somewhere safe, off the phone (see Keep it safe), and open it from there to check it copied before you go on.
  3. Install Crumb from Google Play. To join the testers, follow Join the Crumb beta.
  4. If Google Play will not install over the old copy, that is expected. A copy installed from a file is not the same build as the Google Play one, so Android treats them as different apps. Once the backup file is safe off the phone, uninstall the old copy, then install from Google Play. Uninstalling deletes the diary inside the old copy.
  5. Open Crumb and restore during setup, as in step 3.

A test build (au.crumb.app.debug) installs next to Crumb instead of replacing it. It keeps its own data until you uninstall it, so back it up too if it holds a diary you want.
