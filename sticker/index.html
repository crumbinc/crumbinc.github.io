Stickers live in Crumb, a free food diary for Android. Open the sticker in Crumb, or install Crumb and add it with the code.

Your sticker code

This code adds the sticker to your Stickers page in Crumb.

Keep this code. It also works on a new phone or after a reinstall.

Open in Crumb

Code copied.

On a phone with Crumb, Open in Crumb opens the app and adds the sticker. On a computer, or without Crumb, use the steps below.

  1. Get Crumb

    Join the Crumb beta, then install Crumb from Google Play. It is free.

  2. Open the sticker

    With Crumb installed, tap Open in Crumb above, or tap the sticker link again.With Crumb installed, tap the sticker link you were sent. Crumb opens straight to the sticker. If nothing happens, use the next step.

  3. Or enter the code

    In Crumb, open Me, Stickers, tap the menu, then Enter a code, and paste the code in the Sticker code box. Tap Add sticker.

This page shows a sticker code when the link you opened has one. This link has none, so use the steps above with the code you were sent.

The code is in the part of the link after the #, which your browser never sends to this website. Crumb checks the code on your phone. Nothing is sent anywhere and you do not need an account.
